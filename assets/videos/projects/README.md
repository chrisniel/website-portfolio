# Project Videos

Place only approved, web-optimized public project videos in this folder.

For the planned BantayGabi gameplay clip:

- Prefer a 15–45 second H.264 MP4 at 720p or 1080p.
- Aim for roughly 10–25 MB when the image quality remains acceptable.
- Create a separate WebP poster under `assets/images/posters/`.
- Do not include private notifications, usernames, file paths, debug logs, or unlicensed music.
- Record the final video and poster in `docs/04_Source-Design-Documents/asset-register.md`.
- Add the video to the overview carousel only after Chris approves the final public copy.

The carousel's JavaScript already supports video items without downloading them until selected.
