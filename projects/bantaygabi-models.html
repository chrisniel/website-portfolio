From Unity to the web

Preparing a game asset for interactive viewing

The Blender model receives its visible materials inside Unity using vertex colors, a , and ShaderLab. The GLB exporter converts supported material information into a standard web representation.

  • Exported the model in a browser-compatible GLB format
  • Checked geometry, materials, scale, and appearance after export
  • Kept a rendered image available for devices that cannot display interactive 3D
  • Separated the public preview from the original Unity project files
