# Contributing

This is Chris Daniel's personal portfolio and learning project.

## Before Making Changes

1. Read `AGENTS.md` when using an AI coding assistant.
2. Read `docs/08_Tracking/task.md` for the current state.
3. Update `docs/08_Tracking/implementation-plan.md` when the scope changes.

## Keep Changes Simple

- Use semantic HTML and existing CSS variables and components.
- Preserve keyboard navigation, visible focus, readable contrast, and responsive layouts.
- Do not add a framework, package, backend, database, or paid service without Chris's approval.
- Do not commit secrets or private information.
- Optimize large images, models, and videos before publishing.
- Record asset ownership and licenses in `docs/04_Source-Design-Documents/asset-register.md`.
- Keep live website files at the repository root and under `assets/`; do not add new work under the unused `main-files/` scaffold.

## Verify A Change

- Preview the page in a browser.
- Check the navigation links and theme button.
- Check at a narrow phone width and a wider desktop width.
- Update the walkthrough and `CHANGELOG.md` when behavior changes.
