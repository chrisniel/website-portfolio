# Public Asset Register

Record every externally sourced, collaborative, commissioned, or generated asset before publishing it.

| Website file | Project/section | Creator/source | Permission or license | Required credit | Optimized size | Status |
| --- | --- | --- | --- | --- | ---: | --- |
| _Example: `assets/images/projects/example.webp`_ | _Example project_ | _Chris / source URL_ | _Owned / license_ | _None / credit text_ | _0 KB_ | _Draft_ |

## Rules

- Do not publish an asset when ownership or permission is unclear.
- Record generated images as generated and retain the prompt/source context when useful.
- Do not use random anime characters or artwork copied from search results.
- Confirm that collaborators approve public screenshots or models from shared projects.
- Remove private filenames, usernames, server addresses, chat messages, and personal information from screenshots.
