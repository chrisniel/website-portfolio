# Documentation Map

The documentation is organized by purpose. Add a new file only when it has a clear job and keep the nearest existing document updated instead of duplicating it.

| Folder | Purpose | Current canonical file |
| --- | --- | --- |
| `00_Draft/` | Unapproved sketches and research | `README.md` |
| `01_Project-Status/` | Plain-language status and evidence-based repository reviews | `current-status.md`, `game-repository-onboarding-2026-08-29.md` |
| `02_Production-Planning/` | Ordered content and release work | `content-roadmap.md` |
| `03_Feature-Plans/` | Plans for one future feature before implementation | `3d-showcase-plan.md` |
| `04_Source-Design-Documents/` | Asset ownership, licenses, and source records | `asset-register.md` |
| `05_System-Documentation/` | Verified technical architecture | `static-site-architecture.md` |
| `06_UI-Design/` | Visual and accessibility rules | `style-guide.md` |
| `07_Walkthrough/` | Beginner-friendly editing, usage, and media-preparation guides | `static-portfolio-guide.md`, `project-detail-pages-guide.md`, `game-media-preparation-guide.md` |
| `08_Tracking/` | Active plan and task continuity | `implementation-plan.md`, `task.md` |

## What Does Not Belong Here

- Passwords, tokens, or private contact details.
- Duplicate copies of the README.
- Raw project assets or exported website files.
- Instructions that describe features the repository does not actually have.
