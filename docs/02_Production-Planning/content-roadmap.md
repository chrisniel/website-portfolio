# Content Roadmap

## Phase 1 — Professional Content

- Add verified projects, skills, About information, experience, education, email, and GitHub profile.
- Keep private CV information out of the public site.

## Phase 2 — Real Project Media

- Choose one strong image for BantayGabi.
- Choose one strong image for Kumpuni.
- Choose one useful Minecraft server/documentation image.
- Optimize files and record ownership in the asset register.

## Phase 3 — First Interactive Model

- Select one model that represents the work well.
- Export and optimize it as `.glb`.
- Create a matching WebP poster.
- Test the pair locally and on a phone.
- Implement `<model-viewer>` with click-to-load behavior.

## Phase 4 — Publish

- Create or select the GitHub repository.
- Push the `main` branch.
- Enable GitHub Pages from the repository root.
- Verify navigation, email, GitHub links, images, and mobile layout on the public URL.

## Later, Only If Needed

- Privacy-respecting analytics.
- Custom domain.
- External large-asset hosting.
- Backend/admin tools after manual updates become a real problem.
